算法流程

【用户列表与编号规则】
抽奖截止时间一到，立刻获取所有点赞用户的用户名（X ID）。
将用户名按字母顺序升序排列（A→Z，0→9，_ 符号等按 ASCII 码顺序）。
排列后，从 0 开始依次编号。
假设有 N 个有效用户，则编号为 0, 1, 2, ..., N-1。
此时 N 已确定，名单已公开，不可更改。
公开这份带编号的完整名单（截图或文本均可）。

【随机种子获取规则】
5. 使用 drand 在截止时间之后产生的第 1 个随机值作为种子。
（找到时间戳在截止时间之后、Round 编号最小的那一条记录，其 Randomness 字段的值即为种子，是一个十六进制字符串，如 a3f25c8d1e...）

【中奖计算算法】
6. 将种子（十六进制字符串）转换为十进制大整数。
中奖编号 = （该十进制大整数）除以 N 取余数。
也就是：中奖编号 = 十进制种子 % N
中奖者即为该编号对应的用户。
